# Manchester Component Ideas — Index

Where each Manchester component variant can take its idea from (plan
`docs/superpowers/plans/2026-10-07-manchester-page-run.md`, Task 21). Nothing here is copied into
the repo: the breeder's idea sheets live in
/Users/apple/Downloads/BSUK/bluestaffyuk-cms/Assets/Components-Ideas (42 PNGs, every one opened
with the Read tool for this pass, 2026-10-07), and London's captures and the MFS sheets live
outside git too. Ideas only; every variant is built fresh on BSUK's tokens and carries no
reference-site text or image.

How to read it:
- Thirteen sections, in city-page order. `video` and `puppy-cards` are not used on Manchester's
  page (Phase F ruling 2), so they have no section.
- **hero** and **counter-strip** are three new designs each from the breeder's sheets and offer
  no pool variant (Phase F ruling 3).
- Every other section opens with its two London pool variants (`data/design/city-pool.json`),
  named and placed on the four axes exactly as `design/city-canvas/london/<component>/meta.json`
  records them. Variant `c` of that component may be one of them, refreshed (ruling 4). Each
  file a pool variant cites in its `idea_sources` is cited again in that section, so a refreshed
  copy's `idea_sources` passes `scripts/check_city_canvas.py`.
- Lines for London's captures (`BSUK-refs/london/`) and the MFS sheets restate what London's
  index (`docs/research/london-components/ideas-index.md`) recorded when those files were opened;
  this pass did not re-open them. Lines for the breeder's sheets describe what this pass saw.
