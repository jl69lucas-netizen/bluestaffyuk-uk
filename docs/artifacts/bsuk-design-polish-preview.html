The cause

  • The missing space. src/components/Breadcrumb.astro renders {i > 0 && <span aria-hidden="true">›</span>} {label} inside one <li>. Astro’s compressed output drops the space between the two expressions (dist: <span aria-hidden="true">›</span><span aria-current="page">), and the <ol>’s gap: 8px spaces only whole list items, so the 8px falls before the › and nothing falls after it.
