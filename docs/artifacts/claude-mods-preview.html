Two pipeline mods and one session-stats mod

Each mockup uses London's real state today: STOPs 1–4 approved and row 12 (writing the page) running. Both pipeline designs read the same status file, written by a repo script from what's on disk. The mod draws it and never guesses. Pick A or B; the stats mod ships with either.

A · The Route Map

Docked pane + status line

A metro line through all 21 page-run rows. Rows are stations, the four STOPs are brass diamonds, and the current station pulses. One glance tells you where London is and what is next. Clicking a STOP opens its board.

B · The Breeder's Ledger

Band above the prompt + pane

A stack of ledger cards, one per phase, with a row-tick strip on each. A STOP shows an "Approved" stamp once you've signed it. The phase you're in gets a brass outline. It reads like a checklist rather than a map, and the band above the prompt says only what needs you.
